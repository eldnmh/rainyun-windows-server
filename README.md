## 1 核 2G 的 Windows 能跑什么，跑不动什么

能跑的：一个 WordPress 或静态站配宝塔、1Panel 这类面板；一个后端 API 的课程 demo；5 到 10 人的原版或轻插件 MC 服（版本越低越稳）；签到、爬虫、自动化脚本常驻。100M 带宽对这几件事绰绰有余。

跑不动的：1.18 以后的模组整合包；同一台机器上 MySQL 加多个 Java 进程一起开；浏览器自动化、编译、容器编排这类吃内存的活；几十人同时在线的服。

Windows 比 Linux 多吃内存。2G 里系统先拿走一部分，留给应用的余量不大，这是这一档最实际的限制。想在同一台机器上同时跑数据库和服务端，2 核 4G 起步更现实。

云服务器这条线能查到的 Windows 档只有 1 核 2G 这一档。要几十 G 内存的 Windows 大机器，雨云另有裸金属物理机产品线，第三方测评提到可选 Windows Server、支持 20 元试用一天，报价从每月四五百元起，各家口径不太一致，同样以购买页为准。

## Windows 裸机开服和游戏云面板，差在哪

面板款是点鼠标：进控制台，在 MCSM 里选 Paper、Spigot、Forge 或 Fabric，设端口，一键启动，把 IP 和端口发给朋友。NAT 模式要手动转发 25565，照着教程两三步的事。全程不碰命令行。

Windows 裸机要自己来：装 Java、传服务端 jar、写启动脚本。一份雨云开服教程给的做法是在 jar 同目录新建文本文档，改名 `run.bat`，写进去：


@echo off
java -Xmx2G -Xms512M -jar 核心文件名.jar --nogui
pause


`-Xmx` 后面是最大内存，`-Xms` 是最小内存，`--nogui` 表示不开图形界面、只走命令行，核心文件名换成你下载的那个 jar。最容易踩的坑是 Java 版本：**1.17 以下用 Java 8，1.17 及以上用 Java 17**，版本对不上服务端直接起不来。

## 买到之后怎么连上去

一位写雨云开服教程的作者记录过完整流程，操作是这样：

1. 在管理页复制“远程连接地址”
2. 在系统里搜 `rdp` 或“远程桌面连接”，打开这个软件
3. 填入地址，点左下角“显示选项”，把用户名也填上
4. 填入远程密码，弹出证书提示点确定
5. 进去之后就和操作本地电脑一样

他提到雨云 Windows 系统的用户名“应该都是 Administrator”。这句是他自己的说法，没有官方文档佐证，以你管理页显示的信息为准。他用 i9 机型演示，服务器创建大约 1 分钟就完成了。

还有一条实用提醒：别在服务器上开浏览器，很占内存。1 核 2G 的机器尤其经不起这么折腾，要查资料在自己电脑上查。

## 哪些情况别选它

**玩家在海外。** 雨云机房主要在国内，海外节点相对少。第三方测评也提到它主要面向国内部署，国际访问延迟会偏高。

**想靠关机省钱。** 云服务器关机仍然计费，只有游戏云支持动态计费，关机不计或按小时极少计费。白天没人晚上才开服的，选游戏云。
